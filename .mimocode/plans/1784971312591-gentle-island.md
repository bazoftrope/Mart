# Шаг 9. Результаты и графики — План реализации

## Оценка

**Низкая.** Recharts уже в зависимостях. Модели понятны. 1 API + 1 страница.

### Модели (данные для агрегации)
- `DailyReport`: enrollmentId, dayNumber, totalCalories
- `StreamEnrollment`: streamId, participantId
- `StreamRating`: rank, disciplinePercent, filledDays

---

## Создаваемые файлы

### 1. `src/pages/api/streams/[id]/results.ts`

GET, middleware: `withParticipant`.

Возвращает для текущего участника:
```json
{
  "participant": {
    "dailyCalories": [{ "day": 1, "calories": 1200 }, ...],
    "avgCalories": 1150.5,
    "totalDays": 30
  },
  "streamAverage": [
    { "day": 1, "avgCalories": 980.3 },
    ...
  ],
  "summary": {
    "rank": 3,
    "disciplinePercent": 86.67,
    "filledDays": 26,
    "avgCalories": 1150.5,
    "totalParticipants": 15
  }
}
```

Логика:
- Найти enrollment текущего участника
- Загрузить `DailyReport` для enrollment → dailyCalories, avgCalories
- Загрузить `StreamRating` → rank, disciplinePercent, filledDays
- Для streamAverage: сгруппировать все DailyReport потока по dayNumber, посчитать AVG(totalCalories)
- totalParticipants из StreamRating

### 2. `src/pages/dashboard/marathon/[streamId]/results.tsx`

Страница с:
- Сводка: место, дисциплина %, средние калории, заполнено дней
- Recharts `ResponsiveContainer` + `LineChart`:
  - Линия участника (синяя)
  - Линия среднего по потоку (серая пунктирная)
  - X-axis: номер дня, Y-axis: калории
- Ссылка «← Back to calendar»

Паттерн: identical to rating.tsx (useEffect + fetch + state).

3. Открыть `/dashboard/marathon/[streamId]/results` — виден график и сводка
